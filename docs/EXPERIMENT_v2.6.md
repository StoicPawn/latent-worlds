# v2.6 — Secondary evolution branch

North Star remains **Can science emerge without being selected for?**

The nearer target is deliberately more attainable and is treated as a necessary possible bridge:

> **Can evolution spontaneously invent a faster form of evolution?**

No new agent objective, sensor, action, cultural primitive, imitation rule, teaching rule or inheritance rule is introduced. `secondary_evolution.py` is observer-side only.

A candidate non-genetic evolutionary system must show, before any stronger claim:

1. multiple information variants;
2. receive → later re-emit events across genetic lineages;
3. persistence across generations;
4. differential persistence/fitness across variants;
5. information-variant turnover faster than genealogical turnover.

These are screening criteria, not proof. Any candidate must next survive payload scrambling, channel censorship, lineage transplant and extinction/fixation analysis.

This branch is intentionally compatible with the North Star: if a second inheritance process appears, subsequent experiments ask what it accumulates. Only if it begins accumulating predictive/causal information about hidden world laws do we advance toward spontaneous epistemology and eventually spontaneous science.

## First screening result

Across 16 independent 700-step histories, three strict candidates survived the full observer-side screen (seeds 0, 6 and 7). Their received→reemitted replication fidelity exceeded permutation-null fidelity by approximately 0.10–0.12 (p=0.01 with 99 permutations), with mutation rates roughly 0.51–0.66. Variant propagation numbers were strongly heterogeneous (CV roughly 0.8–1.5), while payload-scrambled controls failed the full candidate criterion and reduced fidelity excess to roughly 0.01–0.02.

This is treated as a *candidate non-genetic inheritance signature*, not as proof of cultural evolution, because all three histories currently reach only generation G1. The preregistered next target is replication-with-variation at G2 or deeper, followed by causal channel censorship, scrambling and fixation/extinction analysis.
