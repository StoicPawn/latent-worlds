# Experiment v2.0 — Causal semantic structure

No agent objective, reward, action, sensor, or physical law was added in v2.0. All changes are observer-side assays.

## Tests

1. **Replication:** apply the same within-receiver content substitution assay to independent population × world candidates and compare real evolution with payload-scrambled evolution.
2. **Causal codebook:** inject every naturally discovered signal-cluster centroid into the same receiver and estimate `P(action | cluster, generation)`.
3. **Directional substitution:** replace a received signal category with another category while holding receiver, world state and RNG fixed, then record directional action transitions.
4. **Generational depth:** report only generations with a minimum sample size; tiny G2/G3 samples cannot count as amplification.

## Current candidate W1 × A1

The candidate still has only G0 and G1 after 3,000 world steps (9 births total), so cultural fixation is not established.

Directional substitution on the readable-evolved population produces four signal clusters. Several cluster substitutions cause strongly asymmetric action changes; the largest observed pair-specific action-kind change rate is about 0.26 in G1. In the matched payload-scrambled evolutionary control, only two clusters are recovered and G1 shows zero action-kind changes under cluster substitution in the sampled events.

This is evidence for content-sensitive receiver structure, not yet language. The main missing criterion is multi-generation fixation and replication of the same qualitative mechanism in independent worlds/populations.
