# Experiment v2.4 — Communicative depth before semantic depth

## Motivation
Generational depth is not cultural depth. In v2.3 several worlds reached G3, but expensive semantic assays still sampled mostly G0/G1. v2.4 adds a cheap observer-side communication-depth screen before any semantic autopsy.

## Pre-registered screen
For each generation, count broadcast emissions and decisions made while receiving at least one signal. A generation is communication-active only if it exceeds fixed minimum emission and reception counts. A candidate for deep cultural analysis must have an active generation >= G2.

This screen changes no world law, action, reward, controller, or evolutionary process.

## First audit of known G3 worlds
Turnover profile: reproduction_threshold=15, reproduction_cost=6, resource_regrowth=0.07.

- W0 × A3: genealogy G3, communication-active generations G0–G1. G2 emitted only 1 broadcast despite 147 reception decisions; G3 emitted none.
- W0 × A4: genealogy G3, communication-active generations G0–G1. G2 emitted 31 broadcasts but had only 8 reception decisions; G3 remained sparse.
- W3 × A0: genealogy G3, communication-active generations G0–G1. G2 emitted 6 broadcasts.
- W3 × A2: genealogy G3, communication-active generations G0–G1. G2 emitted 1 broadcast; G3 emitted none.

## Result
All four known G3 worlds fail the communicative-depth criterion. Their late generations exist demographically but do not sustain a sufficiently bidirectional signalling circuit.

This identifies a sharper bottleneck:

    genealogical persistence != informational persistence

and prevents expensive semantic assays from being spent on genealogically deep but communicatively shallow histories.

## Next target
Search directly for worlds satisfying all three before semantic autopsy:
1. max_generation >= 2;
2. G2 is communication-active under pre-registered thresholds;
3. population is non-collapsing.

Only then test real vs scrambled vs censored semantic causality.
