# v3.4 — Independent adaptive-replication search and visibility acceleration

No agent capability, reward, communication rule, reproduction rule, or physical law
was added in this release.

## Scientific target

The preregistered target remains a second independent history that simultaneously
shows:

1. G2+ active communication;
2. same-agent causal copy effect under signal removal;
3. causal steering under real-payload transplantation;
4. matched-context differential reproduction of emergent signal variants;
5. failure of the corresponding mechanism under scrambled-content evolution;
6. readable fitness above both censorship and scrambling across multiple horizons.

Only histories that pass each earlier stage are allowed to reach later, more
expensive assays.

## Pure engine optimization

The line-of-sight inner loop now uses squared point-to-segment distances rather
than square roots.  Bounding-box rejection and the exact geometric criterion are
unchanged.  This is an implementation optimization only; it changes no world law
or observation rule.

Validation on the world/causal/replication test subset: 39/39 tests passed.

## New-world campaign

### Worlds 106–113

W109 reached G4 genealogically and had G2 communication activity
(16 G2 emissions; 314 G2 receptions), but failed the direct same-agent causal
removal assay.  The single G2 broadcast event in the causal window had negative
copy gain.  W110 and W112 had no sufficiently active G2 communication.

### Worlds 114–125

Late-generation communication candidates were W114, W115, W117, W118 and W123.

- W114: too few G2 causal broadcast events; observed copy gain negative.
- W115: no supported late-generation causal events in the preregistered window.
- W117: G2/G3 received signals but did not naturally rebroadcast in the assay.
- W118: eight G2 payload-effect events had positive mean copy gain (~+0.016), but
  the permutation criterion was not supported.
- W123: the closest candidate.  G3 had 25 natural broadcasts, mean copy gain
  ~+0.0070 and ~82.6% positive events, but permutation p~0.07.  The threshold was
  not relaxed; W123 was rejected.

### Worlds 126–137

Only W135 passed the cheap late-generation communication screen.  Its G2 causal
window contained one natural broadcast with strongly negative copy gain
(~-0.116), so it was rejected immediately.

## Interpretation

The campaign did not produce the desired second persistent adaptive replication.
This is a useful negative result: under unchanged criteria, late-generation
communication is substantially more common than direct causal content copying,
and direct causal copying is substantially more common than persistent adaptive
replication.

The current hierarchy therefore remains:

- W11 x A0: direct causal mechanism + persistent adaptive superiority;
- W21 x A0: independent direct-causal mechanistic replication (G3), not full
  adaptive replication;
- W63 x A0: independent content-specific mechanistic replication (G2), not full
  adaptive replication;
- no second independent history yet satisfies the complete persistent adaptive
  criterion.

The next search should continue unchanged rather than adding agent-side structure.
