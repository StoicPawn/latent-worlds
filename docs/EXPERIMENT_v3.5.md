# v3.5 — Rarity funnel for independent adaptive replication

No agent capability, reward, communication rule, reproduction rule, or world law
was changed in this release.

## Objective

Search for a second independent history that satisfies the full staged criterion:

1. G2+ active communication;
2. direct same-agent causal copy effect under signal removal;
3. content-specific steering under payload transplantation;
4. matched-context differential reproduction;
5. absence of the mechanism after scrambled-content evolution;
6. readable fitness above censorship and scrambling across preregistered horizons.

## New-world campaign

World seeds 138–201 (64 independent worlds, agent seed A0) were screened at the
same turnover profile used in the v3.x replication programme.

Seven worlds reached the late-generation communication prerequisite:
W143, W156, W176, W186, W187, W192 and W196.

Only W187 passed the direct removal stage in G2.  It then failed specificity:
the scrambled-evolution control also supported removal and differential
reproduction.  W187 was therefore rejected before any adaptive claim.

No new content-specific mechanistic replication and no new persistent adaptive
replication were found in this 64-world campaign.

## Attrition funnel

- screened: 64
- late-generation communication: 7 / 64 = 10.94%
- direct causal removal: 1 / 64 = 1.56%
- content-specific after scrambled control: 0 / 64
- mechanistic replication: 0 / 64
- persistent adaptive replication: 0 / 64

Wilson 95% interval for late-generation communication:
[0.0540, 0.2090]

Wilson 95% interval for direct causal removal:
[0.0028, 0.0833]

For zero complete replications in 64 screened histories, the Wilson 95% upper
bound is ~0.0566 for this
particular campaign/protocol.  This is not an estimate of a universal emergence
probability; it is a campaign-specific screening rate.

## Interpretation

The search funnel is strongly selective:

late-generation communication is uncommon; direct causal content copying is much
rarer; content-specific causal replication is rarer still.

The existing status therefore remains:

- W11 x A0: direct causal mechanism + persistent adaptive superiority;
- W21 x A0: independent direct-causal mechanistic replication, not fully adaptive;
- W63 x A0: independent content-specific mechanistic replication, not fully adaptive;
- no second independent persistent adaptive replication yet.

The negative campaign increases confidence that the W11 result is not a generic
property of the architecture, while simultaneously showing that the target
transition is rare enough that future searches should be staged and statistically
accounted for rather than interpreted from cherry-picked histories.
