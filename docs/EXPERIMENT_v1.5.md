# v1.5 — Phase-map protocol

The simulator does **not** claim a true private-information OFF condition: finite local perception already makes evidence agent-dependent. The intervention manipulated here is *additional information fragmentation* generated by occlusion and local physical perturbations.

Accordingly, the primary explanatory variable is the empirically measured `private_information_index`, not the nominal obstacle/pulse multiplier. Nominal intensity is an intervention label only.

A publishable transition requires replication across seeds and all of the following observer-side evidence: null-aware encoding, null-aware receiver uptake, cross-generational persistence, and a positive matched communication × fragmentation interaction. No agent receives any of these scores.
